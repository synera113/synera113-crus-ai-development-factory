# CRUS AI Development Factory

CRUS, yerel öncelikli, çok ajanlı yazılım geliştirme platformudur.

## Phase 1

- FastAPI backend foundation
- SQLAlchemy ile kalıcı veri modeli
- PostgreSQL ve demo SQLite desteği
- Agent, Project ve Task API'leri
- Docker Compose
- Redis yapılandırması
- Windows PowerShell kurulum betikleri
- API testleri

## Çalıştırma

```powershell
./setup.ps1
./start.ps1
```

Backend: http://localhost:8000

API docs: http://localhost:8000/docs
