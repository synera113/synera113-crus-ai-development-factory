CRUS AI Development Factory
===========================

A local-first, modular platform for orchestrating autonomous software development agents.

Phase 1 includes:

- FastAPI application foundation
- SQLAlchemy persistence with SQLite/PostgreSQL support
- Redis-ready infrastructure
- Agent, project and task REST APIs
- Ten registered specialist roles
- Docker Compose deployment
- Windows setup/start/stop scripts
- Automated API tests

English documentation and API references are included in the repository.
